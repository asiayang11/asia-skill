# 视觉风格规范

## 风格定位

使用「暖纸手绘科普手账」作为内部风格名。营造像在旧纸上用黑色笔、彩铅和蜡笔画出的解释板：亲切、温柔、有细节，同时保留工程说明图的清楚结构。将以下参数视为从参考图提炼的建议，不声称是精确取色或固定模板。

## 视觉语法

| 元素 | 建议规格 | 作用 |
| --- | --- | --- |
| 纸底 | 暖奶油 `#F5E9CC`，轻微纤维与淡色斑驳 | 建立温暖底色；文字区减少纹理 |
| 文字与轮廓 | 炭黑 `#29251F`，略微不规则的细描边 | 清楚、手绘、有自然笔触 |
| 对比 A | 低饱和珊瑚粉 `#E7B0A0` | 标题带或局部背景 |
| 对比 B | 灰蓝 `#A5BCD0` | 与 A 成对使用 |
| 强调 | 向日葵黄 `#E9B94F` | 标题划线、结论、星星和关键标记 |
| 植物 | 灰绿 `#899687`，少量棕色 `#9C805E` | 画面边缘与底部装饰 |
| 留白 | 纸底透出；可借用原图的丰富感但降低文本密度 | 让信息可读 |

保持黑色墨线和彩铅/蜡笔质感。为标题色带使用毛边横涂笔触；为强调句使用手绘黄色划线。避免强渐变、厚重阴影、霓虹、玻璃效果、金属质感与写实 3D。

## 版式与比例

- 默认采用接近参考图的横向 16:9；需要移动端阅读时改为 4:5 或拆成多图，重排所有内容而非硬裁切。
- 以约 8–12% 高度放大标题，约 5–8% 放短副标题，约 60–70% 放核心结构，余下区域放结论与装饰；按内容调整。
- 外边距约为短边的 4–6%；纸卡内边距约为短边的 1.5–2.5%。正文与纸卡边缘、箭头都保持间距。
- 对比图默认两列 42% / 42%，中间约 8% 可放关系说明，余下留边距。只有确实有空间时放中央角色；密集内容优先取消中央角色。
- 使用不规则纸框、略卷的边角、很淡的铅笔阴影。内部步骤卡保持稳定对齐，外框的手绘感不要造成歪斜难读。
- 在 1600×900 的规划画布上，标题约 64–80 px，副标题 30–38 px，卡片主文案 28–34 px，次级注释 22–26 px，线条 2–4 px。其他尺寸按比例调整；正文不足时删减或拆图。

## 中文文案与图形

- 使用带笔触的粗中文标题；使用干净可读、稍有手写感的正文。可编辑实现优先选现有 CJK 字体，如 Noto Sans CJK SC；不为手写效果牺牲字形清晰度。
- 默认单标题不超过约 16 个汉字，副标题不超过约 40 个汉字；步骤标题约 6–14 个汉字，补充说明一到两行。这是排版建议，不是截断用户必要信息的规则。
- 将技术术语完整写清；允许少量英文词，不混入随意的伪英文。
- 将主节点画成「图标 + 短动词标题 + 简短说明」。图标使用统一的黑色描边与浅色填充，如机器人、数据库圆柱、拼图、工具、文档和脑。
- 用箭头表达真实关系：顺序使用直箭头，循环使用侧边弧形箭头，反馈使用虚线并标注。装饰虚线与信息连线在位置和含义上区分。
- 对比两侧保持同等文字尺度和相同对比维度。允许步骤数不同，不为视觉对称编造步骤。

## 装饰规则

选择 2–3 类装饰即可。使用向日葵或简单花朵、植物叶片、黄色星星、爱心涂鸦、木牌、书堆、笔、信纸或睡猫。把主要装饰放在边缘、底角或分区间的真正空位，整体占可用面积约 10–18%。角色最多一个主要角色，可配一个很小的次要角色。

参考图的向日葵有圆形深色脸、简单白色眼睛、细枝状四肢；把它当作可选情绪点缀，不绑定为所有主题的固定吉祥物。猫、花、机器人可根据主题替换。小便签适合写一句提醒，底部宽纸卡适合写核心结论。不要机械添加原图的书名、签名、品牌或文字。

## 适配原则

保持材质、线条、颜色、纸卡结构和温暖情绪；放开主题、角色、图标、步骤数、构图比例。参考图中有关 Agent、Skill、Runtime 的内容属于原图主题，不属于风格规范，不迁移到新主题，也不将其成本公式作为通用事实。
