# 蓝紫科技卡片说明图

## 工作流程

1. 识别用户要成图、提示词、布局方案、可编辑文件还是技能修改。只执行当前请求；仅要技能或提示词时不生成图片。
2. 阅读 [视觉规范](references/style-guide.md)。首次制作、要求高度一致或发生风格漂移时查看 `assets/style-reference.png`。参考图只提供视觉语言，不证明其中事件、产品、报价或发布日期的真实性，不沿用其品牌标志、宣传结论和技术内容。
3. 从用户材料提取受众、主题、核心结论、3–8 个信息模块、准确文案与必须保留的限定条件。可做更长摘要但优先拆页。需要新增当前产品、版本、新闻、价格或不确定技术事实时先核实来源；仅抽象风格或使用给定内容时无需为参考图新闻做调查。
4. 阅读 [构图与提示词](references/prompt-patterns.md)，选择发布摘要、产品全景、架构、流程或对比结构。默认中文、竖向 2:3、高分辨率科技简报；流程与宽架构优先横向 16:9。让卡片数量和面积适配内容，不强行凑成参考图的 12 块。
5. 先构造内容蓝图：标题横幅、核心卡片、辅助卡片、编号、状态标签、真实连线或表格、结论。按内容重要性分配面积；每张卡片优先一个主要信息。让编号表达阅读顺序，另用箭头表达真实流程，避免混淆。
6. 选择输出路径：
   - **成图**：使用当前可用的图像生成工具，给出精确文案、布局、风格与负面约束。已查看参考图后，按工具当前引用规则把 `assets/style-reference.png` 作为风格参考，明确重绘新主题。不要把抽象设计复用描述为修改原图中的新闻内容。
   - **仅提示词或方案**：交付填写好主题的提示词或蓝图，不调用图像生成。
   - **精确长中文、代码、价格表、指标图表或复杂架构**：优先 SVG、HTML/CSS 或标准排版与绘图工具，保证文本、数字、连接与比例确定。需要柔光插图时仅生成插图资产，再做确定性排版；不要依靠生成图片保证代码或数据准确。
   - **修改已有图**：以用户当前目标图为编辑对象，只在授权范围修改；原始参考图只作为视觉参考。
   - **工具不可用**：说明可提供的结果，交付完整提示词与蓝图，不声称已生成图片。
7. 执行下方验收。成图或文件可渲染时实际查看，在正常使用尺寸检查文字、溢出和排列。不能查看时说明尚未做视觉检查。不要宣称“中文绝对无错”。
8. 交付指定结果。生成图片按当前工具要求展示，文件按当前保存规则保存；不自动附加多张变体或样例图。

## 核心视觉规则

- 使用近黑深蓝标题横幅与明亮浅色主体形成层级，保持整体像清楚的科技信息简报。
- 使用浅蓝圆角卡片、整齐栅格、稳定间距；以蓝色圆形编号组织阅读。
- 使用深海军蓝文字，少量蓝紫渐变胶囊标签与淡渐变卡片背景，避免满屏高亮。
- 使用粗无衬线标题与清楚中文正文；手写英文仅是可选点缀，不承担关键信息。
- 使用少量柔光玻璃感球体、统一应用图标、界面示意或代码窗口；让视觉为当前主题服务。
- 保留有层次的信息密度，但优先可读性；表格与架构矩阵按内容需要出现，不作为每图必备装饰。

## 验收

- 内容：无未提供的新闻、性能倍数、价格、日期或产品状态；示意界面与真实截图区分；用户限定条件完整。
- 排版：标题—主卡—辅助卡—结论层级清楚；圆角、间距、边线一致；无卡片溢出、挤压、过小文字或孤行。
- 结构：编号顺序清楚；真实关系与装饰分离；矩阵单元准确；对比维度一致；代码语法和表格数字可核对。
- 风格：深色横幅、明亮浅蓝主体、蓝紫强调、清晰文字、少量科技插图成立；未漂移成赛博朋克、全暗界面、厚重玻璃效果或暖纸手账。
- 输出：符合格式与尺寸；用户只要提示词或 skill 时未生成图片；对未验证部分不夸大完成度。
