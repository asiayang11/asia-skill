# 视觉规范

## 风格定位

使用「蓝紫科技卡片简报」描述本风格。呈现现代科技发布会的编辑式信息图：上方深色横幅，下面亮色模块化卡片，辅以蓝紫强调、产品插图、界面示意与结论。保留参考图的紧凑信息层级，避免照搬某一品牌或其发布内容。以下数值为设计建议，不是精确测量或取色结果。

## 设计参数

| 元素 | 建议 | 用途 |
| --- | --- | --- |
| 标题横幅 | 深墨蓝 `#080F22` 到 `#192449`，柔和竖向光带 | 主标题、短副标题、来源与日期（有提供才写） |
| 主体底色 | 冷白 `#F8FBFF` | 稳定阅读背景 |
| 卡片底色 | 冰蓝 `#EAF3FF`，少量淡紫 `#F1EAFF` 渐变 | 模块分区 |
| 正文 | 深海军蓝 `#101936` | 保持明亮底上的高对比 |
| 主强调 | 皇家蓝 `#2466DE` | 圆形编号、箭头、结论 |
| 次强调 | 蓝 `#358CFF` 到紫 `#A44AF4` | 胶囊标签、小型强调块 |
| 状态提示 | 浅粉 `#F8DDE3` 配深红 `#A32A3C` | 仅表达真实状态；同时写出文字 |
| 分隔线 | 淡蓝 `#BED8F7`，细线 | 卡片边框、表格网格 |
| 图形亮色 | 青蓝 `#47CFF3`、淡紫 `#B7A4F4` | 少量插图辉光；不用于小正文 |

## 栅格与尺寸

- 默认竖向 2:3，可按 1600×2400 规划；图像工具未支持具体像素时使用相近比例。宽流程或架构改为 16:9；移动端长图可按 4:5 拆页。
- 标题横幅约占画布高度 10–15%，两侧留边距。让大标题首先被看见，副标题随后，日期和来源再次。
- 主体使用 12 列规划栅格：主卡可跨 7 列，配卡跨 5 列；中段可用 4/4/4 或 3/3/3/3；底部用 6/6。相邻卡片按行对齐，但不同内容允许不同高度。
- 默认 3–8 个模块。若内容确实需要 9–12 个模块，增加高度或拆页，不缩小字体。不要为了像参考图而添加空模块。
- 外边距约画布宽的 1.5–3%；卡间距约 1–1.5%；卡内边距约 1.5–2%。卡片圆角约画布宽的 1–1.5%，阴影低透明、短距离、柔边。
- 在 1600 px 宽画布中，主标题约 70–90 px，副标题 40–48 px，卡片标题 32–38 px，正文 25–30 px，来源注释 20–22 px。按最终阅读尺寸调整，正文保持约 1.4–1.6 倍行高。

## 卡片语法

按「蓝色圆形编号 + 粗标题 + 可选真实状态标签 → 一行核心解释 → 插图/表格/要点」组织单卡。每卡保留 2–5 条短要点；必要长内容分到辅助卡。编号只表示阅读次序，不自动代表处理流程。

标题标签使用短胶囊：如用户给定的「新功能」「实验中」「待确认」。不要凭设计需求给产品标记为已发布、重磅、停用或收费。

用大卡表达核心信息，用小卡补充能力，用矩阵表示层级或角色分工，用左右配对行表示转变。重要限定条件应靠近相关信息，不能仅藏在页脚。

## 字体与图形

- 使用粗无衬线标题和清晰无衬线中文正文。代码用等宽字体；表格数字尽量等宽。使用现有 CJK 字体如 Noto Sans CJK SC，避免缺字或中英文错位。
- 用蓝色粗体强调关键词；只在小标签、强调块或较大标题使用渐变，不对多行正文使用彩色渐变。
- 可在空白角落点缀一到两句用户提供的短英文手写旁注与下划线；默认可以完全省略，避免编造宣传口号。
- 统一应用图标的尺寸、圆角和光照；使用浅色图标底板与轻微柔光。插图可有玻璃/珠光球体、轻量 3D 或全息光泽，但只占局部，不把整张图变成玻璃界面。
- 可按内容放一张浅色界面示意或深色代码窗口。示意界面不得冒充真实产品截图；代码内容先验证或明确为伪代码。不添加不存在的接口和按钮能力。
- 标题横幅可以有抽象光带或细微材质，避免星空、复杂电路、激光和重网格抢走信息。
- 品牌标志仅在用户要求且有合适素材时使用。默认用抽象几何符号或留空；不因参考图有 OpenAI 标志便自动复制。

## 信息准确与适配

参考图中的发布会、年份、型号、定价、状态标签、代码和宣传结论仅属于其示例内容，不属于此技能的事实库。根据每次任务重新获取材料并核实需要的事实。

保持深色横幅、亮色卡片、蓝紫强调、编号层级、清晰密集的编辑式版面；允许主题、品牌、模块数量、角色、插图和表格完全变化。用于单机制解释时减少卡片，用于产品摘要时允许模块较多，用于架构时优先真实拓扑而非栅格对称。
