# 构图与提示词

## 内容蓝图

```text
主题与受众：
任务：成图 / 仅提示词 / 版式 / 可编辑文件
比例：默认竖向 2:3；宽架构或流程使用 16:9
资料：用户内容 / 已核实来源
标题：
副标题：
日期、来源或品牌：未提供则省略
核心结论：
主卡：标题、精准文案、图示
辅助卡：逐卡填写文案
状态标签：只使用已明确的状态
表格/矩阵：逐个单元的值、单位、列与行
真实连接：起点、终点、箭头含义
限定条件：放在相关卡片
```

## 布局选择

| 内容 | 结构 | 注意 |
| --- | --- | --- |
| 发布会或科技简报 | 深色头图；一主一辅；中段功能卡；下方对比或结论 | 日期和新品状态需有依据 |
| 产品功能全景 | 核心产品大卡；4–6 张能力卡；底部能力矩阵 | 不模拟未提供的真实功能 |
| 技术架构 | 深色横幅；分层结构大卡；边栏职责；底部限定条件 | 保留真实连接，必要时横向 |
| 原理流程 | 横向 3–6 节点或竖向分区；解释卡；结论卡 | 编号与流程箭头各有含义 |
| 方案对比 | 两列同维度卡；统一表格；选择建议 | 不为视觉效果编造优势或数据 |

## 生成提示词模板

替换所有占位符，删除未用部分，不把空模板交作具体主题的最终提示词。

```text
制作一张 {比例与尺寸} 的中文科技说明图，主题为「{主题}」，面向 {受众}。
若附有参考图，只借鉴深色横幅、浅蓝卡片、蓝紫强调和编辑式布局；生成新主题，不复制参考图中的产品、事件、代码、价格、日期、标志或宣传结论。

风格：现代科技发布摘要信息图。顶部深墨蓝至近黑横幅，局部柔和蓝紫竖向光带；主体冷白底，冰蓝圆角卡片、淡紫渐变与细淡蓝边线；皇家蓝圆形编号；蓝紫渐变胶囊标签；深海军蓝正文。标题粗无衬线，中文干净清楚，图文层级明确，栅格对齐，间距一致。轻微柔光、浅阴影，图标统一。

布局：{具体卡片数量、排列、主次面积与阅读顺序}。
仅使用以下准确文案：
标题：「{标题}」
副标题：「{副标题}」
{逐卡列出编号、标题、标签、要点和限定条件}
{表格或矩阵逐单元列出内容；未需要则删去}
结论：「{结论}」
连接：{真实箭头起止与标签；不需要则明确无流程连线}。
插图：{主题相关的图示、界面示意或少量玻璃感 3D 资产，以及位置}。

约束：保持亮色主体与清晰信息密度；所有标签、数字、英文和中文逐字准确。不要自动添加新闻、接口、日期、价格、性能倍数、品牌或未经给定的状态。示意界面用「示意」标注。不要生成乱码、重复文案、溢出、过小正文；不做全暗色赛博朋克海报，不添加满屏霓虹电路、强烈炫光、厚玻璃层或手账纸纹。
```

提示词不能保证文字和表格正确。长中文、代码、复杂矩阵或精确数字优先确定性排版：只生成少量无字科技插图，使用 SVG/HTML/CSS 或其他标准工具完成文字与结构；渲染后检查，不无限重试同一个生成提示词。

## 使用示例

- 「使用 $draw-tech-explainers，将这份发布会笔记做成竖版科技摘要长图，只使用笔记里的信息。」
- 「使用 $draw-tech-explainers，解释 agent、loop、harness 的关系，只给提示词。」
- 「使用 $draw-tech-explainers，把我提供的迁移平台模块整理成一张可编辑 SVG 架构图，保留所有条件。」
- 「使用 $draw-tech-explainers，对比这两套方案，突出已给定的成本与功能差异。」

收到技能创建或风格分析请求时，完成对应内容；不要为示范而额外生成图片。
